Skills

A skill is a package of instructions the model may load when a task fits it. The ones below are in ~/.coderagent/skills/. The ones with a source came from the network, the others are yours.

Installed

Built in

These skills come with the agent. A skill of yours with the same name replaces one of them.

Install from the network

A source is a GitHub repository (owner/repo, owner/repo@v1.2.0, owner/repo/skills/pdf-report@v1), the address of one SKILL.md, or a git URL. Nothing is installed before you have read it.

Skill sites

The three sites below are the repositories with the most stars that really hold skills. A click on a skill downloads it and shows what is in it: nothing is installed before you have read it.
